# Data layer

All platform features render from the JSON files in this folder. They are the
single source of truth: the home matrix, hub pages, search, breadcrumbs,
cross-link chips and prev/next navigation all read the same rows.

- `tactics.json` — the 14 Enterprise tactics in ATT&CK order. Never changes.
- `techniques.json` — one row per technique: `id`, `name`, `tactic`,
  `platforms`, `summary` (max 2 neutral sentences), `status`
  (`implemented` | `planned`), `updated` (ISO date). Implemented rows also
  carry `page` and may carry `used_by` (actor IDs), `mitigated_by`
  (mitigation IDs) and `sigma` (rule file paths). Planned rows omit `page`
  and `sigma`.
- `actors.json` — `id`, `name`, `aliases`, `summary`, `status`, `uses`
  (technique IDs).
- `mitigations.json` — `id`, `name`, `type`, `summary`, `status`,
  `mitigates` (technique IDs).
- `campaigns.json` — `id`, `name`, `year`, `summary`, `status`,
  `techniques` (technique IDs).
- `sigma-index.json` — GENERATED by `scripts/build_sigma_index.py` (and by
  CI). It is seeded by hand exactly once, empty, in Phase 2 (so the Phase 3
  counters and Phase 5 search never hit a 404); after that never hand-edit
  it — the next run would overwrite your edit.

## Adding a technique (when a new guide goes live)

1. Copy your hand-written page to `techniques/TXXXX.XXX.html` (official
   ATT&CK casing — GitHub Pages is case-sensitive).
2. In `techniques.json`, find the row (or add it) and set:
   `"status": "implemented"`, `"page": "techniques/TXXXX.XXX.html"`,
   and update `"updated"`. If Sigma rules exist for it, add their file
   paths to the `sigma` array.
3. Run `python scripts/validate_data.py` — it must print all `[OK]` and
   exit 0 before you commit.

## Verification note

Seed relation arrays (`used_by`, `mitigated_by`, `uses`, `mitigates`,
`techniques`) are starter data — verify and extend them against
attack.mitre.org as the site grows.

## JSON hygiene

No trailing commas, no comments, UTF-8 without BOM, one trailing newline.
Run the validator after every edit.
